# Transaction format

This file is the syntax canon: the shape of a transaction and of the postings inside it. What one class of transaction must carry is its aspect skill's (`../skills/ingest/SKILL.md` routes), the comment keys and the order the formatter leaves them in are `../skills/ingest-tags/SKILL.md`'s, an account's meaning is `../reference/account-hierarchy.md`'s, where an entry sits is `editing-guidelines.instructions.md`'s, and the command list is `AGENTS.md`'s.

## The block

```hledger
YYYY-MM-DD [!|*] payee  ; activity: value, time: value, timezone: UTC+08:00
    account:subaccount[:subsubaccount]  [-]amount CURRENCY  [= balance CURRENCY]  [; tag: value]
    account:subaccount                  [-]amount CURRENCY
```

- **Date**: ISO 8601, `YYYY-MM-DD`, and the transaction belongs to the month of that date.
- **Status marker**: `!` pending, `*` cleared, nothing for an ordinary transaction. `!` is what a purchase on `liabilities:credit cards:` takes while the liability stands; what a loan entry's marker means is `../skills/ingest-lending/SKILL.md`'s.
- **Payee**: a name or a UUID that a prelude declares. Printed identifiers sit in parentheses before it, never in a tag; resolving the printed name is `../skills/ingest-payee/SKILL.md`'s and declaring the payee is `../skills/add-payee/SKILL.md`'s.
- **Comment**: `;` then the parts, each `key: value` or a bare note, separated by a comma and a space. Which keys an entry needs is `../skills/ingest-tags/SKILL.md`'s.
- **Posting**: an account, then an amount. A posting left without an amount is inferred from the others, and only one can be.
- **Amount**: two decimals and the commodity after the number, with a space as the thousands separator for four digits or more: `50.00 HKD`, `16 966.42 HKD`. A points commodity may carry no decimals: `100 _PT/B`.

## Alignment

Two spaces between an account and its amount, and two spaces between an amount and a `;` comment. The formatter realigns the columns of a journal it rewrites, so a one-space gap looks ordinary in the file and surfaces only when `hledger` parses the journal, which reads the rest of the line as part of the account name. Longer runs of spaces are alignment, not syntax, and the formatter recomputes them.

```hledger
    expenses:food and drinks:dining       50.00 HKD  ; food_or_drink: sandwich
    assets:digital:Octopus cards:<uuid>  -50.00 HKD
```

## Accounts

- Colons separate the levels, and no account name carries a leading, trailing, or inner space.
- A UUID subaccount is written exactly as its prelude declares it: `assets:banks:<bank-uuid>:HKD savings`.
- The account is the most specific one a prelude declares and the aspect skill names; an undeclared account fails `bun run check:journal`.

## Balance assertions

`= balance CURRENCY` asserts the account's running balance after that posting, so it belongs on the posting whose account it states, normally the last posting touching that account in the entry.

- A transfer's or a loan's posting is the kind that carries one, and a closing block asserts every account it closes to zero. The shape of those blocks is `../skills/migrate/SKILL.md`'s; they are generated by `scripts/clopen.py`, never typed.
- An assertion that no longer matches is recomputed from the account's running balance rather than loosened; removing a posting to make one pass is `../skills/ingest-remove/SKILL.md`'s decision.

## Posting order

Credit postings before debit postings within a transaction: the account that gave up value, then the account that took it.

## Worked examples

A purchase:

```hledger
2025-01-19 Generic Cafe  ; activity: eating, eating: lunch, time: 12:30:15, timezone: UTC+08:00
    expenses:food and drinks:dining       50.00 HKD  ; food_or_drink: sandwich, food_or_drink: coffee
    assets:digital:Octopus cards:<uuid>  -50.00 HKD
```

A conversion: each commodity sums to zero across the transaction, both legs sit on the conversion pair, and no assertion goes on either leg, because the pair account accumulates a balance across entries (`../skills/ingest-currency/SKILL.md`).

```hledger
2025-01-19 Example Exchange  ; activity: transfer, time: 10:15, timezone: UTC+08:00
    assets:cash                               100.00 USD
    equity:conversions:HKD-USD:USD           -100.00 USD  ; rate: 7.78000
    equity:conversions:HKD-USD:HKD            778.00 HKD
    assets:banks:<bank-uuid>:HKD savings     -778.00 HKD
```
